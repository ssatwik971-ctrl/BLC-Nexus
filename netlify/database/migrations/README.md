# Netlify Database migrations

Commit SQL migration files in this directory. Netlify applies committed migrations
as part of deployment. Do not use `prisma db push` against the managed database.

Generate the initial SQL baseline from the Prisma schema with:

```sh
npm run db:generate-sql
```

Review the generated SQL before committing/deploying it. The initial baseline is
intentionally not checked in until it has been generated by Prisma and reviewed.
